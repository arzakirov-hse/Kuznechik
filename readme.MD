3 Программная реализация алгоритма
3.1 Используемые технологии
Для разработки программы использовались:
	язык программирования Python;
	среда разработки PyCharm;
	стандартные библиотеки Python.
Реализация алгоритма была выполнена без использования готовых криптографических библиотек.
3.2 Функциональные возможности программы
Разработанная программа обладает следующими возможностями:
1.	Чтение данных из входного файла. 
2.	Ввод секретного ключа. 
3.	Выбор режима работы: 
	зашифрование;
	расшифрование. 
4.	Сохранение результата в новый файл.
3.3 Структура программы
Программа состоит из следующих основных компонентов:
	модуль генерации раундовых ключей;
	реализация S-преобразования;
	реализация L-преобразования;
	функция зашифрования блока;
	функция расшифрования блока;
	обработка файлов.
