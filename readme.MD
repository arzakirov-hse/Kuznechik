# Kuznechik Cipher (ГОСТ Р 34.12-2015)

Реализация симметричного блочного алгоритма шифрования **«Кузнечик»**  
(стандарт **ГОСТ Р 34.12-2015**) на языке **Python**.

Проект разработан в рамках лабораторной работы по дисциплине **криптография**.  
Алгоритм реализован **самостоятельно без использования готовых криптографических библиотек**.

Программа позволяет выполнять **зашифрование и расшифрование данных из файлов** с использованием секретного ключа.

# Описание алгоритма

Алгоритм **«Кузнечик»** является современным российским симметричным блочным шифром, стандартизированным в ГОСТ Р 34.12-2015.

Основные характеристики алгоритма:

- размер блока — **128 бит**
- размер ключа — **256 бит**
- количество раундов — **10**
- структура — **SP-сеть**

В алгоритме используются следующие преобразования:

- **X-преобразование** — побитовое сложение (XOR) с раундовым ключом
- **S-преобразование** — нелинейная подстановка
- **L-преобразование** — линейное преобразование над полем GF(2⁸)

# Возможности программы

Реализованная программа поддерживает:

- чтение данных из входного файла
- ввод секретного ключа
- выбор режима работы
  - шифрование
  - расшифрование
- сохранение результата в новый файл
- работу с данными в **шестнадцатеричном формате**

# Использование

Программа запускается из командной строки.

## Шифрование

```bash
python kuznechik.py encrypt input.txt output.txt <key>
```

## Расшифрование

```bash
python kuznechik.py decrypt input.txt output.txt <key>
```

---

# Требования к ключу

Ключ должен:

- иметь длину **256 бит**
- содержать **64 шестнадцатеричных символа**

Пример ключа:

```
8899aabbccddeeff0011223344556677fedcba98765432100123456789abcdef
```

---

# Формат входных данных

Входные файлы должны содержать данные **в шестнадцатеричном формате (hex)**.

Пример содержимого файла:

```
1122334455667700ffeeddccbbaa9988
```

Файлы можно редактировать в обычном текстовом редакторе (например, **Блокнот**).
